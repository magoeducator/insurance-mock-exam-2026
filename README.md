# 손해보험·제3보험 온라인 모의고사

2026 개정판 1형부터 20형까지 제공하는 오프라인형 온라인 모의고사입니다. `index.html`에서 유형을 선택하면 각 폴더의 테스트 화면으로 이동합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 생성합니다.
2. 이 폴더의 `index.html`과 `1형`~`20형` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, 폴더는 `/ (root)`로 지정하고 저장합니다.
5. 잠시 후 생성된 GitHub Pages 주소를 교육생에게 공유합니다.

외부 서버나 별도 데이터베이스 없이 HTML 파일만으로 동작하므로 GitHub Pages 무료 호스팅에 적합합니다.
